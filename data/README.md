# Data folder

The public strawberry telemetry benchmark is bundled under `public-strawberry/`. Measured mango air-cargo, bulk-milk tank, commercial apple cold-room, and retail produce-case sources are downloaded under `external/`; see `external/README.md` and `external/manifest.json`. No company data or Qatar/GCC food-shipment outcomes are included. Keep licensed sources and derived datasets in separate subfolders with source/version metadata and a matching update to `docs/DATA_CARD.md`.

`example-telemetry.json` demonstrates the supported JSON upload schema only. Its readings are synthetic and must not be called observed data.
